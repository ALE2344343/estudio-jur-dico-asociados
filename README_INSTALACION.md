# Instalación Rápida del Sistema "Estudio Jurídico & Asociados"

## Requisitos previos en la PC de destino
- **Windows** con **XAMPP** instalado (Apache y MySQL). No es necesario instalar Laravel ni Composer globalmente.
- Tener los **puertos 80 (Apache)** y **8000 (Laravel dev server)** permitidos en el firewall. El script intentará crear la regla del puerto 8000 automáticamente.
- Acceso de **Administrador** para ejecutar el script (necesario para la regla del firewall).

## Pasos para desplegar
1. **Copiar la carpeta del proyecto**
   - Copie toda la carpeta `proyectox` (incluyendo subcarpetas, `.env.example`, `composer.json`, etc.) a la PC destino, por ejemplo:
     ```
     C:\nuevo xap\php\proyectox
     ```
2. **Iniciar XAMPP**
   - Abra el *XAMPP Control Panel* y haga clic en **Start** tanto en **Apache** como en **MySQL**.
   - Verifique que MySQL está activo (puede usar `localhost/phpmyadmin` en el navegador).
3. **Ejecutar el script de arranque**
   - Navegue a la carpeta del proyecto con el Explorador de Windows.
   - Haga clic derecho sobre `INICIAR_SISTEMA.bat` y elija **Ejecutar como administrador**.
   - El script realizará lo siguiente:
     - Detecta el ejecutable `php.exe` (XAMPP o el que tenga en `C:\nuevo xap\php`).
     - Crea la regla de firewall para el puerto **8000**.
     - Verifica que MySQL responde.
     - Genera el archivo `.env` a partir de `.env.example` (si no existe) y ejecuta `php artisan key:generate`.
     - Crea la base de datos `bufete_abogados` si aún no existe.
     - Ejecuta `php artisan migrate --force` y `php artisan db:seed` (si tiene seeders configurados).
     - Crea el enlace `public/storage` con `php artisan storage:link`.
     - Abre el navegador con la URL `http://127.0.0.1:8000`.
     - Finalmente lanza el servidor de desarrollo escuchando en **0.0.0.0:8000**.
4. **Acceder desde otros dispositivos**
   - Obtenga la IP LAN de la PC (ejemplo `192.168.1.5`). En Windows puede usar `ipconfig`.
   - Desde cualquier otro equipo de la misma red, abra el navegador y escriba:
     ```
     http://192.168.1.5:8000
     ```
   - Debería cargar la aplicación sin necesidad de pasos adicionales.

## Solución de problemas comunes
| Síntoma | Posible causa | Acción correctiva |
|---|---|---|
| **Error 403 al abrir documentos PDF** | El enlace `public/storage` no existía. | El script ya ejecuta `php artisan storage:link`. Si el problema persiste, verifique los permisos del directorio `storage/app/public`.
| **La página no carga desde otro PC** | Firewall bloqueando el puerto 8000 o el servidor está escuchando solo en `127.0.0.1`. | El script crea la regla del firewall y usa `--host=0.0.0.0`. Si sigue sin funcionar, abra manualmente el puerto con:
```powershell
netsh advfirewall firewall add rule name="Laravel Bufete" dir=in action=allow protocol=TCP localport=8000
``` |
| **Error al conectar con MySQL** | MySQL de XAMPP no está iniciado o credenciales diferentes. | Asegúrese de haber iniciado MySQL en XAMPP. Si su usuario/contraseña son distintos a `root/` (vacío), edite el archivo `.env` después de la primera ejecución y ajuste `DB_USERNAME` y `DB_PASSWORD`.
| **El script se detiene después de “MySQL no responde”** | MySQL no está corriendo. | Inicie el servicio MySQL y vuelva a ejecutar el script.

## Notas finales
- Este método está pensado para **desarrollo / pruebas** en una red local. Para un despliegue en producción, considere usar un servidor web como **Apache/Nginx** y configurar un virtual host.
- Cada vez que copie el proyecto a una nueva máquina, sólo necesita ejecutar nuevamente `INICIAR_SISTEMA.bat`.
- Si desea cambiar el número de puerto, edite la línea `artisan serve --host=0.0.0.0 --port=8000` del script y la regla del firewall.
